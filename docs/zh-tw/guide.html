簡介

NerLan 是一個「先聽再學」的語言學習 App。它可以播放你加入的任何 Podcast——日語、韓語、英語、法語，你正在學的都行。在一般播放之外，它疊上一整組學習工具：逐句跟著音檔走的 AI 逐字稿、複習講義、逐句翻譯，以及可以錄下自己聲音的跟讀練習。

開始很簡單：打開節目分頁，點一個語言、打開一個節目、點一集開始播。其他的一切——下載、逐字稿、講義——都只再多一個按鍵。

四個分頁

分頁內容
節目你的節目列表，附語言篩選與設定按鈕。
收藏你按過愛心的節目與單集，依節目分組。

只要有載入單集，分頁上方就會浮著迷你播放列：點封面或標題開啟完整播放器。分頁會保留各自的狀態——篩選、捲動位置、打開的節目頁在切換後都還在。

在大螢幕（平板、桌面視窗）上會變成雙欄版面：瀏覽列表縮到左欄，右側自動顯示學習內容——逐字稿、講義或 PDF——邊聽邊讀。

瀏覽節目

節目分頁列出你的節目，依語言分組。最上方是一列篩選 chip；最多人學的語言（英語、日語、韓語、法語）排在前面，點箭頭（展開語言）可以展開全部語言。選擇會被記住；全部顯示所有節目。

每列節目顯示封面、名稱、程度（有標示時，例如初階）與集數（共 N 集）。點開節目頁：

  • 右上角的愛心（收藏節目）收藏整個節目——它會出現在收藏分頁與「我的節目」小工具。
  • 節目介紹預設收合成三行，點一下展開。
  • 單集列表由最早的一集開始，往下捲會自動載入更多。載入過的內容有快取，重開節目頁是即時的。
  • 每一集都有愛心（收藏）與下載按鈕（下載）；點該列開始播放，之後的單集自動排入播放佇列。下拉可以重新整理。

目錄本身也有磁碟快取，離線也能瀏覽、開 App 即顯示；下拉才會抓最新列表。

加入 Podcast

節目分頁右上角的＋開啟新增 Podcast。貼上 Apple Podcasts 連結（podcasts.apple.com 或 apple.co 短網址）或 RSS feed 網址即可——對話框裡的到 Apple Podcasts 搜尋節目會幫你打開瀏覽器搜尋，把節目連結複製回來貼上就好。

訂閱的節目顯示在節目分頁最上方的我的 Podcast（未套用語言篩選時）。長按 Podcast 列可取消訂閱。Podcast 的單集頁和其他節目頁一樣：下拉更新新集數、愛心、下載。

播放器

點迷你播放列開啟完整播放器。

  • 播放控制：上一集 · 倒退15秒 · 播放/暫停 · 快轉15秒 · 下一集，加上可拖曳的進度條。
  • 重複循環切換：不重複 → 重複播放清單 → 重複單集；倍速提供 0.5×–2×。兩者都會被記住。
  • 收藏是單集愛心；下載控制會顯示 下載、進度環或 已下載。
  • 有 PDF 附件的單集會多一個講義按鈕（見 PDF 講義）。
  • 設定好 AI 後會多一列：字幕（播放器內同步逐字稿）、跟讀、逐字稿、AI 講義。

播放在背景繼續，有媒體通知與鎖定畫面控制；拔掉耳機自動暫停；持有喚醒鎖，關螢幕串流也不會中斷。每一集都會記住播放位置，下次接著聽；聽完一集會清掉進度，重聽從頭開始。

下載與串流快取

在任何單集上按下載就能離線收聽——單集的 PDF 講義也會一併自動下載。最多同時下載三個，進度顯示在該列的圓環上。

另外還有串流快取（預設關閉，見設定）：開啟後，串流聽過的音檔會保留下來；完整聽完的一集就成為可離線播放的快取，上限 2 GB，滿了淘汰最久沒用的。

下載分頁把兩種離線內容放在一起，依單集順序排列：

  • 實心勾勾徽章＝已下載（手動下載）；空心、較淡的勾勾＝快取。用實心與否區分，不靠顏色，所以在電子紙螢幕上也一眼可辨。
  • 篩選按鈕（篩選）可只看 全部 / 已下載 / 快取；分段控制可依節目或語言分組。
  • 向左滑刪除本機音檔；長按編輯註記。

設定 AI

逐字稿、講義與翻譯需要語音轉文字模型與對話模型。打開設定（節目分頁的齒輪）——API 來源決定這些請求送到哪裡，兩組設定各自保存：

OpenAI 官方

  • OpenAI API 金鑰——你的金鑰，儲存在裝置上。產生內容使用你自己的 OpenAI 額度。
  • 轉錄模型——whisper-1（回傳時間戳，供同步字幕使用）、gpt-4o-mini-transcribe 或 gpt-4o-transcribe。
  • 講義模型——自由填寫，預設 gpt-4o；用於講義、翻譯與斷句。恢復預設模型還原兩者。

自訂

把 AI 功能指向任何 OpenAI 相容伺服器——通常較便宜，或跑在你自己的機器上（whisperASR、Ollama、代理伺服器）。兩個端點分開設定：

  • 轉錄伺服器——伺服器網址（到 /v1 為止）、轉錄模型、選填的金鑰。用於 /audio/transcriptions。
  • 講義／翻譯伺服器——網址、對話模型、選填金鑰，以及停用思考模式（no think）開關：送出 reasoning_effort=none，讓本機思考模型（qwen3、deepseek-r1 等）跳過思考輸出。用於講義、翻譯與斷句。
  • 每一組都有驗證列——驗證轉錄伺服器／驗證講義／翻譯伺服器——實際送出測試請求，成功打勾，失敗直接顯示伺服器回傳的錯誤訊息。
本機伺服器通常不需要金鑰——金鑰欄留空即可。當自訂網址仍指向 OpenAI 官方位址時，空白金鑰會沿用 OpenAI 模式的金鑰，兩種模式來回切換不用重填。

逐字稿

逐字稿按鈕——在播放器或單集列上——把單集轉成乾淨、有標點的逐句文字。空心圖示代表尚未產生；點一下開始，完成後自動打開。實心圖示代表已存在，點了立即開啟。長按可重新產生或刪除逐字稿。

長單集會以約 20 分鐘為單位分段轉錄；第一段完成就先開給你看，其餘陸續補上，並顯示 轉錄中…（1/3） 這樣的進度。關掉播放器，工作仍會繼續。

在逐字稿畫面裡：

  • 使用有時間戳的模型（whisper-1）時，正在朗讀的句子會醒目顯示並保持置中。在播放器點 字幕 可以把封面換成同樣的同步畫面。
  • 字體大小循環三種字級；複製全部複製全文；逐字稿打開時螢幕不會自動熄滅。
  • 跟讀切換到跟讀模式（見下）；翻譯循環翻譯檢視（見下）。

翻譯

逐字稿的翻譯按鈕循環三種檢視：原文 → 原文＋翻譯 → 只顯示翻譯。雙語檢視中，每一句的翻譯就緊跟在原文下方——先讀原文，下一行立刻對答案。第一次點擊會把內容翻譯成設定裡選的語言（預設繁體中文；也有 English、日本語、한국어、Español、Français、Deutsch、Tiếng Việt、Bahasa Indonesia、ภาษาไทย）。翻譯逐批填入、會快取，也會隨學習資料同步。

打開逐字稿絕不會偷偷啟動付費翻譯——記住的雙語檢視只有在翻譯已經在快取裡時才會還原。

跟讀

跟讀把逐字稿變成口說練習。從播放器的跟讀按鈕進入（需要是正在播放的單集，且逐字稿有時間戳）。練習控制列固定在逐字稿底部，翻譯檢視也照常運作，可以邊看句意邊跟讀。

  • 目前句子會循環播放；點任何一句就跳到那句。
  • 控制列：上一句／下一句、重複這句／停止重複、錄音／停止錄音、播放我的錄音，以及次數按鈕——×1 / ×2 / ×3 / ×5 / ∞。
  • 設定有限次數時，句子播完最後一遍會自動開始錄音；停止錄音後立刻回放，方便和原音比對。
  • 每句保留一段錄音，新的覆蓋舊的。錄音只存在裝置上。

AI 講義

AI 講義按鈕從單集的逐字稿產生複習講義（沒有逐字稿會先自動產生）。每份講義固定四個區塊：內容說明、文法重點、例句（附中文翻譯）、單字（含發音與中文意思的表格）。外語內容保留原文字。

超過約 15 分鐘的單集會分成 Part I / II / III。講義以可縮放的畫面呈現，跟隨深淺色主題；長按按鈕可重新產生或刪除。

PDF 講義

部分單集會隨音檔附上官方 PDF 講義。這些單集會顯示講義按鈕（ⓘ 圖示）——尚未離線保存時是空心，存好後變實心。打開後是全螢幕閱讀器，音檔繼續播放；有多個附件的單集會有選擇附件切換。下載單集音檔時，PDF 會自動一併下載。

AI 資料庫

AI 分頁列出所有已產生逐字稿或講義的單集，可依節目或語言分組——你的學習教材都在這裡，依單集順序排列。這裡的內容不需要設定 AI 也能打開，先前（或從其他裝置同步來）的教材永遠讀得到。

收藏與註記

愛心有兩層：單集（任何單集列或播放器裡的愛心）與整個節目（節目頁的愛心）。兩者都集中在收藏分頁；在那裡向左滑可移除單集。

註記：單集標題常常只有「EP12」，所以你可以幫任何單集寫註記——在任何地方長按單集列（或在節目的單集列表向左滑）打開編輯器。註記會顯示在每個列表的單集標題下方，也會隨學習資料同步。

主畫面小工具

四個可調整大小的小工具，讓練習一按就開始；版面依你給的尺寸自動調整。

繼續收聽

正在播放的單集——封面、進度與剩餘時間——加上倒退 15 秒、播放暫停、下一集按鈕，直接在小工具上操作。較高的尺寸會多出「接下來」清單；沒有載入單集時，會改為建議你最近的下載或收藏。點封面開啟播放器。

最近播放

你正在進行的節目，每列顯示上次聽到的單集與續播進度。播放鍵從停下的地方接續整個節目，之後的單集自動排入佇列；點該列則打開節目的單集列表。

我的節目

收藏節目與訂閱 Podcast 的封面牆，一按就打開節目。預設依最近收聽排序；編輯小工具可自選要顯示哪些節目與順序，還能放多個小工具、各釘選不同組合。

學習紀錄

今日學習分鐘數、連續 N 天與本週總計——最小 2×1 就放得下，空間越大數字越大。開啟雲端同步後，數字會跨裝置合併。點擊開啟 App。

Google 雲端同步

在設定 → Google 雲端同步登入並開啟同步到 Google 雲端硬碟。你的學習資料——收藏、單集註記、Podcast 訂閱、逐字稿、翻譯、AI 講義與聆聽統計——會同步到雲端硬碟的私人應用程式資料夾，並在多部裝置間合併。音檔、PDF 與跟讀錄音不會上傳。立即同步可手動觸發；狀態列會顯示進度與結果。

統計

設定 → 統計有兩個畫面：

  • 使用統計——總聆聽時間、完成單集、連續聆聽天數、今日／本週／本月，日／週／月趨勢圖，以及最常聽的節目。多裝置同步後合併計算。
  • 資料統計——儲存空間盤點：收藏、下載與佔用空間、講義附件、快取大小、AI 內容數量，以及已下載內容的語言分布。

設定總覽

從節目分頁的齒輪開啟。

API 來源
切換OpenAI 官方 或 自訂——見設定 AI。兩組設定都會保存，切換不會遺失。
翻譯語言
選單逐字稿翻譯的目標語言。預設：繁體中文。
置中捲動動畫
開關播放時把朗讀中的句子平滑捲到畫面中央。預設開啟；電子紙裝置建議關閉以避免殘影。
串流時自動快取
開關保留串流聽過的音檔，聽完整集即可離線重播。預設關閉。清除快取音檔 可清空。
Google 雲端同步
登入、同步開關、立即同步、登出——見同步。
清除所有 AI 內容
動作確認後刪除所有已儲存的逐字稿與 AI 講義。
統計
使用統計 與 資料統計——見統計。

小技巧

  • 電子紙裝置：關閉 置中捲動動畫，逐字稿會逐句跳頁而不是平滑捲動；下載／快取徽章以實心與否區分，不靠顏色。
  • Deep link：nerlan:// 協定可以從任何地方開啟 App——nerlan://player（播放器）、nerlan://show?id=…（節目單集列表）、nerlan://tab?name=programs|favorites|downloads|ai（切換分頁）。小工具用的就是這些，自動化工具也可以用。
  • 不會偷跑：AI 內容只在你明確點擊時才產生；串流也只在你開啟快取後才保存。
