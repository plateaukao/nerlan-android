用聽的學語言，
而且真的學得起來。

NerLan 播放你用來學語言的 Podcast，並把每一集變成學習教材：與音檔同步的 AI 逐字稿、複習講義、逐句翻譯，以及跟讀練習。

下載 閱讀使用說明

為什麼叫「NerLan」？

一個名字，兩種讀法——而且兩種都成立。

唸出來

Ner·Lan 就是 near language——靠近一種語言。學語言真正的距離，不是你背了多少單字，而是你離「聽得懂剛剛那句」還有多遠。

拆開看

六個字母剛好是 N + LEARN，不多不少。而 LEARN 的五個字母，正好就是這個 App 做的五件事。

  1. LListen 聽你訂閱的任何 Podcast，依你正在學的語言分類。
  2. EEcho 跟讀循環播放一句、錄下自己的朗讀，再和原音比對。
  3. AAnnotate 講義每一集一份 AI 複習講義：文法、例句、單字。
  4. RRead 讀逐字稿與翻譯跟著音檔走，一句一句對照。
  5. NNote 記收藏、下載與學習資料，同步保存不遺失。

它能做什麼

你的節目、你的訂閱

從 Apple Podcasts 或 RSS 加入任何節目，再依你正在學的語言分類整理——日語、韓語、英語等等。

跟著播放走的逐字稿

一鍵把單集轉成乾淨的逐句文字。播到哪一句，哪一句就保持醒目並置中。

AI 複習講義

每一集一份講義：內容說明、文法重點、例句，以及附發音的單字表。

逐句翻譯

把逐字稿翻譯成你的語言，原文與譯文對照閱讀，或只看翻譯。

跟讀練習

設定次數重複播放一句、錄下自己的朗讀，再回放比對。

離線、同步、主畫面

下載單集連同 PDF 講義、自動快取串流過的音檔、透過 Google 雲端硬碟同步學習資料，還有每日練習的小工具。
